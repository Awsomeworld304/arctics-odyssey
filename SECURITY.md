# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this game, **please do not post it publicly**.

- Use the [Report a vulnerability](https://github.com/Awsomeworld304/arctics-odyssey/security/advisories/new) button in this repository’s Security tab to submit a private report directly to us.

- Or email us at: jamestech4849@gmail.com

We will respond to your report as quickly as possible, typically within 7 days.

## Supported Versions
Currently, only the latest version of the game is supported.

## Disclosure Policy

We will work with you to confirm and fix vulnerabilities before disclosing them publicly.

Thank you for helping keep this project and its players safe!
